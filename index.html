01About

I like projects where code meets something tangible: sound you can hear, data you can watch move, or a tool that saves someone an afternoon of manual work. A lot of what I build starts as a school assignment or a personal itch and grows from there.

Lately I've been working with TypeScript, React and Next.js on the web, Python and Django on the backend, and C++ with Raylib whenever I want something fast and visual. Away from the keyboard — well, a different keyboard — I'm learning pieces on the piano. A few recordings live on the Piano page.
